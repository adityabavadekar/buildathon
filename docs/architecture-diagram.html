Four things that deliberately refuse to run

  • A structural mandate failure is never retried. A revoked mandate cannot succeed, so a retry only spends gateway fees.
  • An indeterminate authorization is never retried. A timeout hides whether the charge already went through, so it reconciles first rather than risking a double charge.
  • A degraded rail suppresses per-case action. A rail-wide spike is not a per-customer problem.
  • An unsigned webhook is rejected with 401 in production, and a case past ANALYSIS_QUEUED will not open a duplicate on redelivery.
